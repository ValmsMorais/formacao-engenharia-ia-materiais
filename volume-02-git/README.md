# Volume 02 - Git e Engenharia de Software

Materiais práticos do Volume 02 da **Formação Engenharia de IA**.

Repositório oficial: https://github.com/ValmsMorais/formacao-engenharia-ia-materiais

## Antes de começar

Baixe os materiais e faça uma cópia de `projeto/processador-transacoes/` para uma pasta de estudos fora deste repositório. Abra essa cópia no VS Code e execute nela os comandos do livro.

A pasta original funciona como referência. A cópia é o local em que você criará o repositório, os commits, as branches e o conflito controlado.

## Estrutura e momento de uso

- `GUIA_AMBIENTE.md`: preparação e validação do Git.
- `projeto/processador-transacoes/`: projeto-base que será copiado e evoluído nas sprints.
- `templates/README_PROJETO.md`: roteiro para a Sprint 2.
- `templates/ISSUE_FEATURE.md`: apoio para a Issue da Sprint 3.
- `templates/PULL_REQUEST_TEMPLATE.md`: apoio para a Pull Request da Sprint 3.
- `desafios/conflito/README.md`: laboratório controlado da Sprint 4.
- `desafios/checklist-seguranca.md`: revisão antes de commits e pushes.
- `referencias/comandos-git.md`: consulta rápida dos comandos usados no volume.

> O projeto usa apenas dados fictícios. Nunca publique credenciais, tokens ou informações reais de ambientes corporativos.
