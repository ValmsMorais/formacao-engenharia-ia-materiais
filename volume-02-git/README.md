# Volume 02 - Git e Engenharia de Software

Materiais práticos do Volume 02 da **Formação Engenharia de IA**.

Repositório oficial: https://github.com/ValmsMorais/formacao-engenharia-ia-materiais

## Estrutura
- `projeto/processador-transacoes/`: projeto-base para os laboratórios de Git.
- `templates/`: modelos de README, Pull Request e Issues.
- `desafios/`: exercícios de conflito e segurança.
- `referencias/`: folha de consulta dos comandos usados no volume.

> O projeto usa apenas dados fictícios. Nunca publique credenciais, tokens ou
> informações reais de ambientes corporativos.
