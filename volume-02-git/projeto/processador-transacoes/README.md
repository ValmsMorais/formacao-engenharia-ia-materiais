# Processador de Transacoes
Projeto guiado do Volume 01. Comece pela Sprint 1 do livro e evolua esta pasta gradualmente.

Entrada inicial: `data/entrada/transacoes.csv`.
A pasta `data/saida/` inicia vazia e recebera os arquivos produzidos pelo seu programa.

## Testes

Na raiz deste projeto:

```bash
python -m pytest -q
```

O arquivo `pytest.ini` mantém a importação do pacote `src` consistente também quando `pytest -q` é usado diretamente.
