# Preparando o ambiente - Volume 02

1. Instale Git pela fonte oficial: https://git-scm.com/
2. Valide com `git --version`.
3. Configure:
   `git config --global user.name "Seu Nome"`
   `git config --global user.email "seu-email@example.com"`
4. Valide as duas configurações.
5. Abra o projeto no VS Code e use o terminal integrado.

## Segurança
Nunca publique senhas, tokens, chaves privadas, `.env` real ou dados corporativos.

As tarefas locais não exigem GitHub. Para operações remotas, o curso começa com HTTPS e apresenta SSH depois.
