# Checklist antes do push

- [ ] `git status` foi revisado.
- [ ] `git diff --staged` foi revisado.
- [ ] Não há `.env`, tokens, senhas ou chaves privadas.
- [ ] Arquivos gerados e logs não foram adicionados por engano.
- [ ] Os testes locais passaram.
- [ ] A mensagem do commit descreve a intenção da mudança.
