# Volume 04 - HTTP, APIs e FastAPI

Materiais práticos da Formação Engenharia de IA.

- `exemplos/`: exemplos pequenos e progressivos.
- `exercicios/`: atividades sem solução.
- `gabaritos/`: referências de solução para os exercícios 01, 02 e 03.
- `referencias/`: comandos e lembretes HTTP.
- `projeto/api-transacoes/`: evolução do projeto cumulativo.

O projeto entregue é o ponto de partida: inicialmente, ele disponibiliza apenas `GET /api/v1/status`. Os endpoints de clientes, transações e importações devem ser implementados durante as missões do PDF. O exercício e o gabarito do cliente HTTP pressupõem que os endpoints de clientes já tenham sido concluídos.

Todos os dados e credenciais de exemplo são fictícios.
