# API de Transações

Projeto cumulativo do Volume 04.

## Ambiente
1. Crie `.venv`.
2. Instale `requirements.txt`.
3. Copie `.env.example` para `.env` e ajuste localmente.
4. Garanta que o banco do Volume 03 esteja disponível.
5. Execute `fastapi dev app/main.py`.
6. Acesse `/docs`.
7. Na raiz do projeto, rode `python -m pytest`.

Não publique `.env`.
