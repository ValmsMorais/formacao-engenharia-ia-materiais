# Preparando o ambiente - Volume 01

Antes dos laboratórios:

1. Instale uma versão estável e suportada do Python 3.
2. Valide no Windows com `python --version` e/ou `py --version`.
3. Instale o Visual Studio Code.
4. Instale a extensão Python da Microsoft.
5. Use `Python: Select Interpreter` para selecionar o interpretador.
6. Ao chegar à seção de dependências, crie/ative `.venv`.
7. Instale as dependências com:

```powershell
py -m pip install -r requirements.txt
```

Em macOS/Linux, a chamada do interpretador costuma ser `python3`.

Nunca coloque senhas, tokens ou dados corporativos reais nos exercícios.
