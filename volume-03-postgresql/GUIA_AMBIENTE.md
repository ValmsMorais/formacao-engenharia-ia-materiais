# Preparando o ambiente

1. Instale PostgreSQL estável pela fonte oficial.
2. No Windows, o instalador recomendado inclui PostgreSQL Server e pgAdmin.
3. Crie o database `engenharia_ia`.
4. Teste no Query Tool:

```sql
SELECT version();
```

5. Para Python, crie `.venv` e instale as dependências do projeto.

Nunca versione senha real no Git.
