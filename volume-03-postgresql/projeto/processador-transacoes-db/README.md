# Processador de Transações Persistente

Evolução do projeto cumulativo da Formação Engenharia de IA.

1. Copie `.env.example` para `.env` e ajuste apenas localmente. O projeto carrega esse arquivo com `python-dotenv`.
2. Crie/ative `.venv`.
3. Instale `requirements.txt`.
4. Crie o database `engenharia_ia`.
5. Aplique o schema/migrations.
6. Implemente `src/importar.py` seguindo as missões do PDF e execute a importação.
7. Rode os testes com `python -m pytest -q`.

Nunca publique `.env`.
